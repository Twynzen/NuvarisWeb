TU TAREA: TESTING VISUAL CON ANTIGRAVITY
==========================================

Como Claude con acceso visual, necesito que hagas testing interactivo y reportes lo que ves.

PASOS A SEGUIR:

1. STARTUP (5 minutos)
   - npm install
   - npm run start
   - Selecciona cualquier personaje
   - Verifica: Juego carga, player visible, enemigos aparecen
   - Busca: Errores en consola

2. DEBUG VISUALIZATION (10 minutos)
   - Presiona Ctrl+D para activar debug
   - DEBE VER:
     * Círculo VERDE alrededor del player (collision radius)
     * Círculos ROJOS alrededor de enemigos
     * Línea CYAN formando perímetro del mapa
     * Cuadrados AMARILLOS (sprite bounds)
   - Presiona Ctrl+D de nuevo → debe desaparecer todo

3. COLISIONES (15 minutos)
   - Acerca player a un enemigo con WASD/Flechas
   - Observa cuando los círculos se tocan
   - Health debe disminuir cuando toca (damage visible)
   - Prueba con múltiples enemigos
   - Verifica: Enemigos lejanos (> 35 unidades) NO causan daño

4. PERFORMANCE (10 minutos)
   - Deja juego corriendo 2-3 minutos
   - Abre DevTools (F12) → Console
   - Busca errores o warnings
   - Verifica FPS: Con Ctrl+D ON y OFF
   - Cuenta: ¿Cuántos enemigos hay en pantalla?

5. EDGE CASES (10 minutos)
   - Player en esquina + múltiples enemigos → ¿Daño correcto?
   - Movimiento muy rápido (WASD spam) → ¿Colisiones funcionan?
   - Múltiples enemigos en misma posición → ¿Sin crashes?
