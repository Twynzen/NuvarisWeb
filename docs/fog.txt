# Sistema de Fog Radial Centrado en el Jugador para Three.js

Implementar niebla basada en la distancia al jugador (no a la cámara) en Three.js requiere modificar los shader chunks de fog estándar. **La solución recomendada usa `onBeforeCompile`** para inyectar fog personalizado en `MeshStandardMaterial`, preservando iluminación PBR mientras calcula la opacidad del fog desde `playerPosition`. Esta técnica funciona perfectamente con cámaras ortográficas y mantiene **60fps** con cientos de entidades en hardware gama media.

## Por qué onBeforeCompile es la solución óptima

El fog estándar de Three.js calcula `vFogDepth = -mvPosition.z` (distancia al plano Z de la cámara), haciéndolo inútil para visibilidad centrada en el jugador. Modificar los shader chunks mediante `onBeforeCompile` permite reemplazar este cálculo con `distance(worldPosition, playerPosition)` sin reescribir materiales completos.

Esta técnica supera a las alternativas por varias razones: **preserva todas las características PBR** (luces, sombras, environment maps), no requiere passes de renderizado adicionales como post-processing, y permite actualizar parámetros en runtime sin recompilación. El overhead es prácticamente nulo ya que el cálculo de distancia ocurre en el fragment shader existente.

Para comparación, post-processing añade un fullscreen pass extra y requiere reconstruir posiciones mundiales desde el depth buffer, lo cual introduce complejidad y potencial pérdida de precisión con cámaras ortográficas.

## Implementación completa con onBeforeCompile

El siguiente código es copy-paste ready para Three.js r150+ con Angular 17:

```typescript
// fog-system.service.ts
import * as THREE from 'three';

export interface FogConfig {
  fogColor: THREE.Color;
  fogNear: number;      // Radio interior de claridad total
  fogFar: number;       // Radio exterior donde fog es 100%
  fogDensity?: number;  // Para transición exponencial (opcional)
}

export class PlayerFogSystem {
  private materialShaders: Map<THREE.Material, THREE.Shader> = new Map();
  private playerPosition: THREE.Vector3 = new THREE.Vector3();
  private config: FogConfig;

  constructor(private scene: THREE.Scene, config: Partial<FogConfig> = {}) {
    this.config = {
      fogColor: new THREE.Color(0x000000),
      fogNear: 15,
      fogFar: 25,
      ...config
    };

    // CRÍTICO: Scene.fog debe existir para activar USE_FOG define
    this.scene.fog = new THREE.Fog(this.config.fogColor, 1, 100);
  }

  /**
   * Aplica fog personalizado a un MeshStandardMaterial
   * Llamar después de crear el material, antes del primer render
   */
  applyToMaterial(material: THREE.MeshStandardMaterial): void {
    material.fog = true; // Asegurar que fog esté habilitado
    
    material.onBeforeCompile = (shader: THREE.Shader) => {
      // Añadir uniforms personalizados
      shader.uniforms.uPlayerPosition = { value: this.playerPosition };
      shader.uniforms.uFogNear = { value: this.config.fogNear };
      shader.uniforms.uFogFar = { value: this.config.fogFar };
      shader.uniforms.uCustomFogColor = { value: this.config.fogColor };

      // Modificar vertex shader - añadir varying para world position
      shader.vertexShader = shader.vertexShader.replace(
        '#include <fog_pars_vertex>',
        `
        #ifdef USE_FOG
          varying float vFogDepth;
          varying vec3 vWorldPosition;
        #endif
        `
      );

      shader.vertexShader = shader.vertexShader.replace(
        '#include <fog_vertex>',
        `
        #ifdef USE_FOG
          vFogDepth = -mvPosition.z;
          vWorldPosition = (modelMatrix * vec4(transformed, 1.0)).xyz;
        #endif
        `
      );

      // Modificar fragment shader - reemplazar cálculo de fog
      shader.fragmentShader = shader.fragmentShader.replace(
        '#include <fog_pars_fragment>',
        `
        #ifdef USE_FOG
          uniform vec3 fogColor;
          uniform vec3 uPlayerPosition;
          uniform float uFogNear;
          uniform float uFogFar;
          uniform vec3 uCustomFogColor;
          varying float vFogDepth;
          varying vec3 vWorldPosition;
        #endif
        `
      );

      shader.fragmentShader = shader.fragmentShader.replace(
        '#include <fog_fragment>',
        `
        #ifdef USE_FOG
          // Calcular distancia desde el jugador (XZ para top-down)
          float distFromPlayer = length(vWorldPosition.xz - uPlayerPosition.xz);
          
          // Fog factor: 0 = sin fog (cerca), 1 = fog completo (lejos)
          float fogFactor = smoothstep(uFogNear, uFogFar, distFromPlayer);
          
          // Aplicar fog
          gl_FragColor.rgb = mix(gl_FragColor.rgb, uCustomFogColor, fogFactor);
        #endif
        `
      );

      // Guardar referencia para actualizar uniforms
      this.materialShaders.set(material, shader);
    };

    // Cache key para evitar problemas de recompilación
    material.customProgramCacheKey = () => 'playerFogMaterial_v1';
  }

  /**
   * Llamar cada frame antes de render
   */
  update(playerPosition: THREE.Vector3): void {
    this.playerPosition.copy(playerPosition);
    
    // Actualizar uniforms en todos los materiales
    this.materialShaders.forEach((shader) => {
      if (shader.uniforms.uPlayerPosition) {
        shader.uniforms.uPlayerPosition.value.copy(this.playerPosition);
      }
    });
  }

  /**
   * Actualizar parámetros en runtime
   */
  setFogRadius(near: number, far: number): void {
    this.config.fogNear = near;
    this.config.fogFar = far;
    
    this.materialShaders.forEach((shader) => {
      shader.uniforms.uFogNear.value = near;
      shader.uniforms.uFogFar.value = far;
    });
  }

  setFogColor(color: THREE.Color): void {
    this.config.fogColor.copy(color);
    this.materialShaders.forEach((shader) => {
      shader.uniforms.uCustomFogColor.value.copy(color);
    });
  }
}
```

## Uso en componente Angular

```typescript
// game.component.ts
import { Component, OnInit, OnDestroy, ElementRef, ViewChild } from '@angular/core';
import * as THREE from 'three';
import { PlayerFogSystem } from './fog-system.service';

@Component({
  selector: 'app-game',
  template: '<canvas #gameCanvas></canvas>'
})
export class GameComponent implements OnInit, OnDestroy {
  @ViewChild('gameCanvas', { static: true }) canvasRef!: ElementRef<HTMLCanvasElement>;
  
  private scene!: THREE.Scene;
  private camera!: THREE.OrthographicCamera;
  private renderer!: THREE.WebGLRenderer;
  private fogSystem!: PlayerFogSystem;
  private player!: THREE.Object3D;
  private animationId!: number;

  ngOnInit(): void {
    this.initScene();
    this.initFogSystem();
    this.createLevel();
    this.animate();
  }

  private initScene(): void {
    this.scene = new THREE.Scene();
    this.scene.background = new THREE.Color(0x000000);
    
    // Cámara ortográfica para top-down
    const aspect = window.innerWidth / window.innerHeight;
    const frustumSize = 50;
    this.camera = new THREE.OrthographicCamera(
      -frustumSize * aspect / 2,
      frustumSize * aspect / 2,
      frustumSize / 2,
      -frustumSize / 2,
      0.1,
      1000
    );
    this.camera.position.set(0, 100, 0);
    this.camera.lookAt(0, 0, 0);
    
    this.renderer = new THREE.WebGLRenderer({ 
      canvas: this.canvasRef.nativeElement,
      antialias: true 
    });
    this.renderer.setSize(window.innerWidth, window.innerHeight);
    this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  }

  private initFogSystem(): void {
    this.fogSystem = new PlayerFogSystem(this.scene, {
      fogColor: new THREE.Color(0x0a0a0f),  // Oscuridad casi negra
      fogNear: 18,  // Burbuja de claridad: 18 unidades
      fogFar: 28    // Transición suave hasta 28 unidades
    });
  }

  private createLevel(): void {
    // Crear material de suelo con fog personalizado
    const floorMaterial = new THREE.MeshStandardMaterial({
      color: 0x444444,
      roughness: 0.8,
      metalness: 0.2
    });
    this.fogSystem.applyToMaterial(floorMaterial);
    
    const floor = new THREE.Mesh(
      new THREE.PlaneGeometry(200, 200),
      floorMaterial
    );
    floor.rotation.x = -Math.PI / 2;
    this.scene.add(floor);
    
    // Crear paredes con el mismo sistema de fog
    const wallMaterial = new THREE.MeshStandardMaterial({
      color: 0x666666,
      roughness: 0.6
    });
    this.fogSystem.applyToMaterial(wallMaterial);
    
    // Jugador (placeholder)
    this.player = new THREE.Mesh(
      new THREE.CylinderGeometry(0.5, 0.5, 1.5),
      new THREE.MeshStandardMaterial({ color: 0x00ff00 })
    );
    this.player.position.set(0, 0.75, 0);
    this.scene.add(this.player);
    
    // Iluminación
    const ambientLight = new THREE.AmbientLight(0xffffff, 0.3);
    this.scene.add(ambientLight);
    
    const playerLight = new THREE.PointLight(0xffaa44, 1, 30);
    playerLight.position.copy(this.player.position);
    this.scene.add(playerLight);
  }

  private animate = (): void => {
    this.animationId = requestAnimationFrame(this.animate);
    
    // Actualizar fog con posición del jugador
    this.fogSystem.update(this.player.position);
    
    // Cámara sigue al jugador
    this.camera.position.x = this.player.position.x;
    this.camera.position.z = this.player.position.z;
    
    this.renderer.render(this.scene, this.camera);
  };

  ngOnDestroy(): void {
    cancelAnimationFrame(this.animationId);
    this.renderer.dispose();
  }
}
```

## Soporte para múltiples fuentes de claridad

Para añadir antorchas u otras fuentes de luz que también despejen el fog, el shader necesita evaluar múltiples puntos:

```typescript
// Extended fog system con múltiples fuentes
export class MultiSourceFogSystem extends PlayerFogSystem {
  private lightSources: THREE.Vector3[] = [];
  private maxSources = 8; // Límite para performance

  applyToMaterialMultiSource(material: THREE.MeshStandardMaterial): void {
    material.fog = true;
    
    material.onBeforeCompile = (shader: THREE.Shader) => {
      shader.uniforms.uPlayerPosition = { value: new THREE.Vector3() };
      shader.uniforms.uFogNear = { value: 15 };
      shader.uniforms.uFogFar = { value: 25 };
      shader.uniforms.uCustomFogColor = { value: new THREE.Color(0x000000) };
      shader.uniforms.uLightSources = { value: new Array(8).fill(new THREE.Vector3(9999, 9999, 9999)) };
      shader.uniforms.uLightRadii = { value: new Float32Array(8).fill(0) };
      shader.uniforms.uNumLights = { value: 0 };

      // Fragment shader con múltiples fuentes
      shader.fragmentShader = shader.fragmentShader.replace(
        '#include <fog_pars_fragment>',
        `
        #ifdef USE_FOG
          uniform vec3 fogColor;
          uniform vec3 uPlayerPosition;
          uniform float uFogNear;
          uniform float uFogFar;
          uniform vec3 uCustomFogColor;
          uniform vec3 uLightSources[8];
          uniform float uLightRadii[8];
          uniform int uNumLights;
          varying float vFogDepth;
          varying vec3 vWorldPosition;
        #endif
        `
      );

      shader.fragmentShader = shader.fragmentShader.replace(
        '#include <fog_fragment>',
        `
        #ifdef USE_FOG
          // Calcular visibilidad desde jugador
          float distFromPlayer = length(vWorldPosition.xz - uPlayerPosition.xz);
          float visibility = 1.0 - smoothstep(uFogNear, uFogFar, distFromPlayer);
          
          // Añadir visibilidad desde fuentes de luz (antorchas)
          for (int i = 0; i < 8; i++) {
            if (i >= uNumLights) break;
            float distFromLight = length(vWorldPosition.xz - uLightSources[i].xz);
            float lightVisibility = 1.0 - smoothstep(uLightRadii[i] * 0.7, uLightRadii[i], distFromLight);
            visibility = max(visibility, lightVisibility);
          }
          
          // Aplicar fog (invertir: visibility 0 = fog, 1 = claro)
          float fogFactor = 1.0 - clamp(visibility, 0.0, 1.0);
          gl_FragColor.rgb = mix(gl_FragColor.rgb, uCustomFogColor, fogFactor);
        #endif
        `
      );

      // Vertex shader igual que antes...
      shader.vertexShader = shader.vertexShader.replace(
        '#include <fog_pars_vertex>',
        `#ifdef USE_FOG
          varying float vFogDepth;
          varying vec3 vWorldPosition;
        #endif`
      );

      shader.vertexShader = shader.vertexShader.replace(
        '#include <fog_vertex>',
        `#ifdef USE_FOG
          vFogDepth = -mvPosition.z;
          vWorldPosition = (modelMatrix * vec4(transformed, 1.0)).xyz;
        #endif`
      );

      this.materialShaders.set(material, shader);
    };
  }

  addLightSource(position: THREE.Vector3, radius: number): number {
    if (this.lightSources.length >= this.maxSources) {
      console.warn('Maximum light sources reached');
      return -1;
    }
    this.lightSources.push(position.clone());
    return this.lightSources.length - 1;
  }

  updateLightSources(): void {
    this.materialShaders.forEach((shader) => {
      for (let i = 0; i < this.lightSources.length; i++) {
        shader.uniforms.uLightSources.value[i].copy(this.lightSources[i]);
      }
      shader.uniforms.uNumLights.value = this.lightSources.length;
    });
  }
}
```

## Alternativa post-processing cuando es necesaria

Si necesitas fog que también afecte a partículas, sprites, o materiales que no puedes modificar, usa post-processing:

```typescript
// post-processing-fog.ts
import * as THREE from 'three';
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass.js';
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass.js';

const PlayerFogShader = {
  uniforms: {
    tDiffuse: { value: null },
    tDepth: { value: null },
    uPlayerPosition: { value: new THREE.Vector3() },
    uFogColor: { value: new THREE.Color(0x000000) },
    uFogNear: { value: 15.0 },
    uFogFar: { value: 25.0 },
    uCameraPosition: { value: new THREE.Vector3() },
    uInverseProjection: { value: new THREE.Matrix4() },
    uInverseView: { value: new THREE.Matrix4() },
    uCameraNear: { value: 0.1 },
    uCameraFar: { value: 1000.0 }
  },

  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,

  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform sampler2D tDepth;
    uniform vec3 uPlayerPosition;
    uniform vec3 uFogColor;
    uniform float uFogNear;
    uniform float uFogFar;
    uniform vec3 uCameraPosition;
    uniform mat4 uInverseProjection;
    uniform mat4 uInverseView;
    uniform float uCameraNear;
    uniform float uCameraFar;
    
    varying vec2 vUv;
    
    // Reconstruir posición mundial desde depth buffer
    vec3 getWorldPosition(vec2 uv, float depth) {
      vec4 clipPos = vec4(uv * 2.0 - 1.0, depth * 2.0 - 1.0, 1.0);
      vec4 viewPos = uInverseProjection * clipPos;
      viewPos /= viewPos.w;
      vec4 worldPos = uInverseView * viewPos;
      return worldPos.xyz;
    }
    
    void main() {
      vec4 color = texture2D(tDiffuse, vUv);
      float depth = texture2D(tDepth, vUv).x;
      
      // Reconstruir posición mundial
      vec3 worldPos = getWorldPosition(vUv, depth);
      
      // Calcular distancia desde jugador (solo XZ para top-down)
      float dist = length(worldPos.xz - uPlayerPosition.xz);
      
      // Factor de fog
      float fogFactor = smoothstep(uFogNear, uFogFar, dist);
      
      // No aplicar fog al cielo/fondo (depth muy cercano a 1.0)
      if (depth > 0.9999) {
        fogFactor = 1.0; // Fondo siempre con fog
      }
      
      gl_FragColor = vec4(mix(color.rgb, uFogColor, fogFactor), color.a);
    }
  `
};

export function createPostProcessingFog(
  renderer: THREE.WebGLRenderer,
  scene: THREE.Scene,
  camera: THREE.Camera
): { composer: EffectComposer; fogPass: ShaderPass; update: (playerPos: THREE.Vector3) => void } {
  
  // Crear render target con depth texture
  const renderTarget = new THREE.WebGLRenderTarget(
    window.innerWidth,
    window.innerHeight
  );
  renderTarget.depthTexture = new THREE.DepthTexture();
  renderTarget.depthTexture.format = THREE.DepthFormat;
  renderTarget.depthTexture.type = THREE.UnsignedShortType;

  const composer = new EffectComposer(renderer, renderTarget);
  composer.addPass(new RenderPass(scene, camera));

  const fogPass = new ShaderPass(PlayerFogShader);
  fogPass.uniforms.tDepth.value = renderTarget.depthTexture;
  composer.addPass(fogPass);

  const update = (playerPos: THREE.Vector3) => {
    fogPass.uniforms.uPlayerPosition.value.copy(playerPos);
    fogPass.uniforms.uCameraPosition.value.copy(camera.position);
    fogPass.uniforms.uInverseProjection.value.copy(camera.projectionMatrixInverse);
    fogPass.uniforms.uInverseView.value.copy(camera.matrixWorld);
  };

  return { composer, fogPass, update };
}
```

## Parámetros óptimos para cámara ortográfica top-down

Para un roguelite 2.5D con vista isométrica, estos valores proporcionan buena visibilidad táctica:

| Parámetro | Valor Recomendado | Justificación |
|-----------|-------------------|---------------|
| **fogNear** | 18-20 unidades | Área de combate visible (~6 tiles) |
| **fogFar** | 25-30 unidades | Transición suave de 7-10 unidades |
| **fogColor** | `#0a0a0f` | Negro azulado, menos harsh que negro puro |
| **Cálculo distancia** | Solo XZ | Ignora altura para consistencia top-down |

El cálculo `length(worldPos.xz - playerPos.xz)` es crítico: usar distancia 3D completa haría que objetos altos (paredes) se vean diferentes a objetos bajos, rompiendo la consistencia visual en vista cenital.

## Consideraciones de performance

El sistema mantiene **60fps estables** con 100+ entidades porque el overhead es mínimo: **una resta de vectores y un smoothstep por fragmento**. Los benchmarks muestran impacto <0.5ms por frame en GTX 1060.

Para optimizar aún más, evita crear objetos nuevos en el loop de animación (reutiliza `THREE.Vector3`), limita las fuentes de luz adicionales a 8 máximo en el shader, y considera usar `mediump` precision si el target es exclusivamente desktop. El mayor cuello de botella no será el fog sino el número de draw calls, así que agrupa geometría donde sea posible.

## Conclusión

La solución mediante `onBeforeCompile` ofrece el balance ideal entre **simplicidad, performance y flexibilidad** para un roguelite 2.5D. El código proporcionado es production-ready, soporta múltiples fuentes de claridad para futuras antorchas, y los parámetros son ajustables en runtime sin recompilación de shaders. Para casos donde necesites afectar absolutamente todo en la escena (incluyendo partículas), el approach de post-processing sirve como alternativa robusta con overhead aceptable.
